# Thangs API Integration Guide

Version 1

This guide walks you through integrating your application with the Thangs API. It covers obtaining an API key, making authenticated requests from your service layer, getting a user's authorization to access their data, and managing your 3D models, their parts, and their images.

The guide has three parts:

- [Getting started](./getting-started.md) covers what every request needs.
- [Plans and user memberships](./plans-and-memberships.md) covers reading your plans and checking which of them a user subscribes to.
- [Model management](./model-management.md) covers creating and updating your models, their parts and their images.

Plans and user memberships and Model management are independent of each other, so use either or both. Where calls within a part must happen in order, that part says so. Each endpoint has a reference table with its exact inputs and outputs.
