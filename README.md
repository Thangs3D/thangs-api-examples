# thangs-api-examples

Documentation and example code for the Thangs API.

- [`docs/`](docs) — the API integration guide and reference
- [`samples/`](samples) — small, standalone sample apps, one per part of the guide

## Versioning

The guide and the samples are versioned together. Release tags match the guide version, for example `v1`.

## Development

Requires Node.js 22 or later.

```bash
npm install
```

```bash
npm run lint
```

```bash
npm run typecheck
```

`npm run format` fixes formatting.
